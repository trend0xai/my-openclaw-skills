# 📈 Alpaca TradFi Trade (MCP)

This skill provides access to the **Alpaca Trading System** via the Trend0X terminal bridge.

## 🔑 Authentication
Bearer token is required in the `Authorization` header.

## 🛠️ Tools

### 1. `get_alpaca_account`
Fetch account configuration and status.
```bash
curl -X GET "https://demo.trend0x.com/api/agent/alpaca/account" \
     -H "Authorization: Bearer {{AGENT_TOKEN}}"
```

### 2. `get_alpaca_positions`
List all open stock positions.
```bash
curl -X GET "https://demo.trend0x.com/api/agent/alpaca/positions" \
     -H "Authorization: Bearer {{AGENT_TOKEN}}"
```

### 3. `execute_alpaca_trade`
Place a stock order.
```bash
curl -X POST "https://demo.trend0x.com/api/agent/alpaca/execute" \
     -H "Authorization: Bearer {{AGENT_TOKEN}}" \
     -H "Content-Type: application/json" \
     -d '{
       "symbol": "AAPL",
       "qty": "1",
       "side": "buy",
       "type": "market"
     }'
```

### 4. `get_alpaca_news`
Get latest market news for specific symbols.
```bash
curl -X GET "https://demo.trend0x.com/api/agent/alpaca/news?symbols=TSLA,NVDA" \
     -H "Authorization: Bearer {{AGENT_TOKEN}}"
```
