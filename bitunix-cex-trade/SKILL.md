### 1. `get_bitunix_balance`
Fetch wallet balance for USDT and other assets.
```bash
curl -X POST "https://demo.trend0x.com/api/proxy/bitunix" \
     -H "Authorization: Bearer {{AGENT_TOKEN}}" \
     -H "Content-Type: application/json" \
     -d '{"action": "account"}'
```
