# 📥 Antigravity Task Funnel (MCP)

Manage autonomous agent workflows within the Trend0X ecosystem.

## 🛠️ Tools

### 1. `list_tasks`
Get all active and historical tasks.
```bash
curl -X GET "https://demo.trend0x.com/api/tasks" \
     -H "Authorization: Bearer {{AGENT_TOKEN}}"
```

### 2. `create_task`
Initiate a new autonomous agent workflow.
```bash
curl -X POST "https://demo.trend0x.com/api/tasks" \
     -H "Authorization: Bearer {{AGENT_TOKEN}}" \
     -H "Content-Type: application/json" \
     -d '{
       "prompt": "Analyze BTC/USDT on 4h timeframe and identify fractal breaks",
       "type": "AUTO",
       "label": "Market Analysis"
     }'
```

### 3. `update_task_status`
Update the progress or status of a specific task.
```bash
curl -X PUT "https://demo.trend0x.com/api/tasks/TASK_ID" \
     -H "Authorization: Bearer {{AGENT_TOKEN}}" \
     -H "Content-Type: application/json" \
     -d '{
       "status": "completed",
       "progress": 100
     }'
```
